# 完成标准

## 项目默认检查范围

- 只做当前改动的基础检查：读取修改结果、核对关键内容与引用、执行 `git diff --check`；涉及行为变化时运行直接相关的最小测试。
- 题目解析核对关键推导和答案；Notion 写入后读取本次新增或更新部分，确认层级、内容和公式。
- 检查通过后停止，不默认进行全量回归、大批量数值穷举、逐项重复比对或额外视觉检查；出现失败或明确疑点时，仅补充定位所需检查。

## 正弦差商极限完成标准

- PNG 原图和附件 SHA-256 一致，Markdown 非空、相对图片引用有效，归档日期与时间标识一致。
- 注明完整原始题干未展示；核对和差化积、系数 2 的约去、固定 x、非零增量及弧度制前提。
- 通过 x=0、x=π/2 的直接代入核对答案，不用待证明的导数公式证明基本极限。
- Notion 复用既有年/月/日层级，仅新增一组带 2026-10-19_14-04-41 标识的题干/解析；复读本次新增正文与公式。
- git diff --check 通过，仅提交本次文件，推送后核对远端哈希。
